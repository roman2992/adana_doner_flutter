# Адана донер — Flutter prototype

Прототип меню и корзины для кафе «Адана донер» / «Вкус Турции».

## Что работает
- Категории меню и цены, перенесённые с предоставленного фото.
- Добавление блюд, изменение количества и подсчёт суммы.
- Форма оформления: имя, телефон, самовывоз/доставка и комментарий.
- Демонстрационное подтверждение заказа.

## Важно
Это клиентский прототип. Заказ пока **не отправляется** в кафе: для реального запуска нужно подключить сервер/API или CRM, определить номер/канал приёма заказов, адрес кафе, зоны и стоимость доставки, способы оплаты и политику обработки персональных данных. Валюта на фото не указана, поэтому прототип показывает цены без обозначения валюты. Уточните валюту перед публикацией.

## Сборка APK
1. Установите Flutter SDK и Android Studio (с Android SDK и platform-tools).
2. Распакуйте проект и откройте терминал в папке `adana_doner_flutter`.
3. Создайте Android-обвязку Flutter (выполнить один раз): `flutter create --platforms=android .`
4. Затем выполните:

```bash
flutter doctor
flutter pub get
flutter build apk --release
```

APK появится здесь:

`build/app/outputs/flutter-apk/app-release.apk`

Для APK, который можно установить на большинство современных Android-телефонов, используйте обычный `app-release.apk`.

## Установка на Samsung Galaxy S25 Ultra
**Через USB:**
1. На телефоне откройте Настройки → Сведения о телефоне → Сведения о ПО.
2. Нажмите 7 раз на «Номер сборки», чтобы включить параметры разработчика.
3. В Параметрах разработчика включите «Отладка по USB».
4. Подключите телефон к компьютеру и подтвердите разрешение отладки.
5. Из папки проекта выполните `flutter devices`, затем `flutter install --release`.

**Установить APK вручную:** скопируйте `app-release.apk` на телефон, откройте файл в «Мои файлы» и разрешите установку из этого источника, если Android запросит.

## Изменение меню
Список блюд находится в `lib/main.dart` в константе `foods`. Каждое блюдо содержит id, название, описание, категорию, цену и emoji-иллюстрацию. Фото исходного меню находится в `assets/menu_board.jpg`.
